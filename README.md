Cafe Ordering Management System ☕

A desktop-based Cafe Ordering Management System developed using Java AWT and Swing. This project helps manage customer orders, menu selection, and bill generation through an interactive GUI.

~Features
- Order management
- Menu system
- Bill calculation
- GUI using Java Swing & AWT
- Easy-to-use interface

~Technologies Used
- Java
- AWT
- Swing
- NetBeans IDE

~Purpose of the Project

This project was created to demonstrate GUI-based desktop application development using Java and to understand event handling and management system concepts.
